# بازبینی اتصال — ۲۴ اکتبر ۲۰۲۶

منبع: `SHOP-API.html` همان فایل رسمی Backend. معماری، ظاهر و Socket-free بودن دو پروژه حفظ شده است. فقط فرانت و مستندات تغییر کرده‌اند.

## انجام‌شده
- تطبیق مسیرهای جدید، هدرهای Auth و AppVersion، Envelope و نگاشت محصولات/برند با قرارداد رسمی.
- جداکردن حالات پرداخت/پردازش/ارسال و عدم اعتماد به returnURL بانکی.
- حفظ Idempotency-Key برای mutationهای مالی، پشتیبانی از stateهای پردازشی و polling محدود.
- حفظ Tenant scope، عدم جایگزینی null با صفر، عدم فعال‌سازی قابلیت‌های غیرفعال Backend.

## اعتبارسنجی و مرزها
- تست‌های Node و کنترل معماری در همین خروجی با `npm run check` قابل اجرا هستند. برای JSON/JSX از parse مستقل استفاده شده است.
- Build نهایی Next.js در محیط ساخت بدون نصب وابستگی‌ها تأیید نشده و E2E با Backend واقعی اجرا نشده است.
- سامانه اپ مدیریت Gateway (ساخت فروشگاه، انتشار، انبار، DNS، ساخت و مدیریت Bot/Channel) جزو این دو فرانت عمومی نیست و اضافه نشده است.
- راه‌اندازی HTTPS، Host/Origin معتبر، حساب/ربات تست، Billing و Payment callback به تیم استقرار وابسته است.
