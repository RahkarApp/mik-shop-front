# موارد تکمیلی که تیم فرانت باید با تیم بک‌اند/استقرار هماهنگ کند

مرجع اصلی کد Backend: `SHOP-API.html` مورخ ۲۰۲۶/۱۰/۲۳. APIهای Checkout، OTP، پرداخت آنلاین و مدیریت فروشگاه در آن **پیاده‌سازی‌شده** توصیف شده‌اند. فهرست قبلی APIهای «هنوز ساخته‌نشده» منسوخ است.

**نیازهای هماهنگی عملیاتی:** دامنه و TLS/Host معتبر برای Proxy؛ آدرس Origin ثابت Shop؛ تنظیم online payment و returnPath؛ تنظیم روش‌های ارسال و انبار؛ آماده‌بودن UCRM/OTP؛ دادن فروشگاه آزمایشی ACTIVE و کالای دارای VariantId؛ تأیید جریان callback بانکی. تنها Backend صاحب حساب/رزرو/قیمت/پرداخت است.

**دامنه تغییر مجاز:** فقط فرانت‌های مشتری. فرم‌های اپ مدیریت Gateway و سرویس‌های Shop/Telegram/PIM خارج از این دو پروژه‌اند. توسعه APIهای اختیاری (Wishlist، Review، Coupon، Returns) باید همراه FeatureFlag سمت Backend انجام شود؛ تا قبل از آن `false` بمانند.
